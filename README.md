# Deloitte Virtual Internship – Data Analytics & Forensic Technology
Completed a virtual internship with Deloitte via Forage, gaining hands-on experience in data visualization using Tableau and data analysis in Excel. Worked on telemetry analysis and forensic technology tasks involving downtime insights and pay equality classification. 

## Overview
This project was completed as part of the Deloitte Virtual Internship offered through Forage. It simulates real-world tasks performed by Deloitte professionals in data analytics and forensic technology roles. The internship provided hands-on experience in data visualization, classification, and business insights.

## Key Tasks
- Telemetry Dashboard (Tableau):
Analyzed machine downtime data across factories and device types. Built interactive Tableau dashboards to identify unhealthy machine statuses and highlight operational inefficiencies.

- Pay Equity Analysis (Excel):
Performed classification of employee equity scores to detect unfair and highly discriminative pay patterns. Applied basic forensic analysis techniques to understand compensation discrepancies.

## Skills Gained
- Data Visualization with Tableau

- Data Cleaning & Classification in Excel

- Analytical Thinking

- Real-world Business Problem Solving
